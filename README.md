# Website Mockup Generator

Place website screenshots into browser, laptop, desktop, phone, tablet, and multi-device presentations. Screenshots stay pixel-accurate; only scale, position, rotation, clipping, shadows, and compositing change.

```bash
nvm use
npm install
npm run dev
```

Requires Node 22 (see `.nvmrc`). Open [http://localhost:3000](http://localhost:3000), choose a mockup, upload the screenshots that layout needs, then download a 3200×2000 WebP.
